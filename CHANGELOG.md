# Changelog

## 0.1.0 — 2026-09-26

- Publish the first stable GitHub release under Apache 2.0.
- Preserve rc.6 runtime code, controls, styles, dependencies and version-1 preset format.
- Update package metadata, download links and documentation for version 0.1.0.
- Keep official Pascal cloud integration separate from this independent plugin release.

## 0.1.0-rc.6 — prepared 2026-09-26

- Put the visual sun compass and light-balance sliders before technical inputs.
- Add pointer, touch and keyboard compass controls with accessible direction labels.
- Use a device-local date/time picker with explicit zone display and daylight-saving validation.
- Keep precise numeric values, north alignment and JSON in Advanced; add preset file upload.
- Preserve version-1 configuration and renderer behaviour; no new runtime dependencies.
- Add browser coverage for visual/manual parity, files, clock changes and narrow layouts.

## 0.1.0-rc.5 — prepared 2026-09-26

- Prepare independent review source and npm-format artifact with two clean rebuilds and checksums.
- Qualify the public plugin contract against Pascal core/editor/viewer 1.0.3.
- Use publisher-scoped `blackforestdude:daylight`; earlier `local:daylight` is not auto-migrated.
- Add tested host save/restore examples and document shared-viewer integration explicitly.
- Keep companion ceiling/glazing corrections separate from the plugin package.
- Include a synthetic enclosure/glazing lab without customer projects or assets.

The rc.5 and rc.6 entries describe earlier review candidates. Official-cloud deployment remains
a separate host-integration step.
